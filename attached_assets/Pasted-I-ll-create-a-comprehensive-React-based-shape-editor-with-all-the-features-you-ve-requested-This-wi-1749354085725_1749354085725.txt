## Key Features:

### 1. **Shape Types with Toggle Controls**
- Rectangle, Square, Circle, Ellipse
- Line (with variable number of points)
- Curves (Poly, Bezier, Cubic, Quadratic, NURBS) with open/closed options
- N-sided Polygon (3-12 sides)
- Advanced shapes: Star, Blob, Ring

### 2. **Procedural Properties**
- Fill: Solid color (RGBA) or gradient
- Stroke: Color (RGBA) and thickness
- Each shape has randomized procedural properties when generated

### 3. **Interactive Transform Tools**
- **Move**: Click and drag shapes
- **Scale**: Proportional scaling
- **Rotate**: 15-degree increments
- **Skew**: X and Y axis skewing
- **Flip**: Horizontal and vertical flipping

### 4. **Group/Compose System**
- Select multiple shapes (hold Shift for multi-select)
- Click "Compose Shapes" to create a group
- Groups inherit all transform capabilities

### 5. **Scattering System**
Two scatter modes:
- **On Points**: Scatters new shapes on the vertices of the target shape
- **Inside Area**: Randomly scatters shapes within the bounds of the target

## How to Use:

1. **Toggle shape types** in the sidebar to control which shapes can be randomly generated
2. **Click "Generate Random Shapes"** to add new shapes to the canvas
3. **Select shapes** by clicking on them (Shift+click for multiple selection)
4. **Transform selected shapes** using the control buttons
5. **Compose multiple shapes** into groups when 2+ shapes are selected
6. **Enable scatter mode** and click on any shape to scatter new shapes onto it

The app uses object-oriented design with a base Shape class and specialized classes for each shape type. All shapes support the full range of transforms and can be composed into complex symbols. The canvas automatically updates at 60fps for smooth interactions.
